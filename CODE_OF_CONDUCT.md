# Code of Conduct

## Our Commitment

Open Alumni Network is committed to providing a welcoming, respectful, and inclusive environment for everyone involved in the project.

We welcome contributors regardless of experience level, background, identity, education, profession, nationality, or technical ability.

## Expected Behaviour

Participants are expected to:

- Communicate respectfully and constructively
- Welcome different perspectives and experiences
- Give and accept feedback professionally
- Respect personal boundaries and privacy
- Avoid harassment, discrimination, or intimidation
- Focus discussions on improving the project
- Support new and first-time contributors

## Unacceptable Behaviour

Unacceptable behaviour includes:

- Harassment or discriminatory language
- Personal attacks or insults
- Publishing private information without consent
- Deliberate disruption of discussions
- Repeatedly ignoring contributor guidelines
- Misuse of project communication channels
- Threatening, abusive, or intimidating conduct

## Reporting

Concerns should be reported privately to the project maintainer.

Reports will be reviewed fairly and confidentially. Appropriate action may include a warning, removal of content, temporary restriction, or exclusion from the project community.

## Scope

This Code of Conduct applies to:

- Repository issues
- Pull requests
- Discussions
- Project communication channels
- Events and meetings connected to the project

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. Enforcement decisions should be proportionate, documented where appropriate, and focused on protecting the community.
