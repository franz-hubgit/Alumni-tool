# Contributing

Thank you for your interest in Open Alumni Network.

The project is currently in an early planning and prototyping phase. Contributions are welcome from developers, designers, students, alumni, university society representatives, and others interested in community infrastructure.

## Current Contribution Areas

At this stage, useful contributions include:

* Feedback on the project concept
* User research and use-case development
* Privacy and security considerations
* Accessibility recommendations
* Interface wireframes and user journeys
* Technical architecture proposals
* Documentation improvements
* Suggestions for the MVP scope

## Before Contributing Code

Please open an issue before starting a substantial implementation. This allows contributors to discuss the proposed approach and avoid duplicated work.

## Contribution Process

1. Review the existing issues and roadmap.
2. Open or select an issue.
3. Describe the proposed contribution.
4. Fork the repository and create a focused branch.
5. Submit a pull request explaining the change.
6. Respond to review comments where necessary.

## Project Principles

Contributions should support the following principles:

* Privacy by design
* Accessibility
* Transparent community governance
* Institutional independence
* Reusability across universities
* Clear and maintainable documentation
* Respectful collaboration

## Code of Conduct

All contributors are expected to communicate respectfully and constructively. A formal Code of Conduct will be added as the contributor community develops.
