# User Stories

This document outlines the main user needs for the Open Alumni Network MVP.

## Student User Stories

- As a student, I want to create a verified profile so that alumni know who I am and which community I belong to.
- As a student, I want to indicate which conferences I plan to attend so that I can connect with relevant alumni.
- As a student, I want to search for alumni by industry, location, expertise, or conference attendance.
- As a student, I want to request an introduction or meeting with an alumnus.
- As a student, I want to discover side events, networking opportunities, and alumni gatherings around a conference.
- As a student, I want to request funding or practical support for travel, participation, or event organization.
- As a student, I want to learn from alumni who have previously attended similar conferences.
- As a student, I want control over which personal information is visible to other members.

## Alumni User Stories

- As an alumnus, I want to create a profile describing my experience, expertise, location, and interests.
- As an alumnus, I want to indicate which conferences and events I will attend.
- As an alumnus, I want to specify how I am willing to support students.
- As an alumnus, I want to respond to mentoring, introduction, meeting, or funding requests.
- As an alumnus, I want to organize or participate in side events.
- As an alumnus, I want to offer professional introductions, advice, venues, access, or financial support.
- As an alumnus, I want control over who can view my profile and contact me.

## Society or Program Administrator User Stories

- As an administrator, I want to verify students and alumni before they join the community.
- As an administrator, I want to create and manage conference and event listings.
- As an administrator, I want to review funding and support requests.
- As an administrator, I want to manage community roles and permissions.
- As an administrator, I want to moderate inappropriate or misleading content.
- As an administrator, I want to review reports and protect members from misuse.
- As an administrator, I want to invite new students and alumni to the platform.

## Platform Moderator User Stories

- As a moderator, I want to review reported profiles, messages, events, and funding requests.
- As a moderator, I want to restrict or suspend accounts that violate platform rules.
- As a moderator, I want to support community administrators with difficult cases.
- As a moderator, I want administrative actions to be documented and traceable.

## Platform Administrator User Stories

- As a platform administrator, I want to create and manage communities.
- As a platform administrator, I want to assign moderator and administrator roles.
- As a platform administrator, I want to monitor system activity and security issues.
- As a platform administrator, I want to manage privacy, data access, and account deletion requests.
